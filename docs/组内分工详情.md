## 二、黄海彬（40%）— 游戏核心逻辑 + 数据结构

### 负责文件

`src/game.c`        1,823行      | 游戏全部规则逻辑
`include/game.h`    45行         | 游戏逻辑接口声明
`include/common.h`  277行        | 公共枚举、结构体、常量
`src/common.c`      114行        | 工具函数实现

### 技术栈
C 语言

### 具体职责
- 地图生成：墙壁、障碍物、食物、道具的随机放置
- 蛇移动：`StepPlan` 决策-执行分离模式，N 步增长机制
- 碰撞检测：单蛇自身碰撞、双蛇互碰（头碰头/碰身体）
- 道具系统：11 种道具类型的生成、拾取、效果
- 弓箭飞行物：发射、飞行、命中判定、无主箭矢
- 随机事件：地图轰炸（3 区爆破）+ 刀光箭影（边界射箭）
- 计分系统：速度档影响食物分值
- 时间判定：限时模式倒计时、多人模式时间到比分数
- 随机数生成：LCG 高位取模

## 三、卢麒云（30%）— 图形渲染 + UI 界面 + 粒子特效

### 负责文件

`src/render_easyx.c` 2,119行  | 全部图形渲染和 UI
`include/render.h`   70行     | 渲染接口声明

### 技术栈
C 语言 + EasyX 图形库

### 具体职责
- EasyX 窗口管理：分辨率切换、全屏适配（Win32 修改窗口样式）
- 贴图系统：3 套皮肤（像素森林/霓虹夜行/冰原挑战）共 48 张贴图加载
- 菜单 UI：渐变背景 + 编号卡片按钮 + 装饰小蛇动画 + 飘浮粒子
- 游戏内 HUD：棋盘左上/右上/底部信息条 + 卡片化侧栏（分数/道具/事件/速度档）
- 棋盘渲染：大地图局部视口（以蛇头为中心）、地面纹理平铺
- 粒子系统：200 粒子池 + 吃食物/死亡/轰炸触发
- 动画效果：分数弹跳、预警脉冲、死亡红闪、文字发光/描边
- 霓虹灯效：霓虹夜景皮肤的棋盘灯光动画
- 轰炸区视觉：红色警告 → 橙色预警 → 深红爆破三态
- 分辨率适配：`menuScale` + `hudScale` 自动缩放

## 四、刘景炫（30%）— AI 决策 + 输入系统 + 音频 + UI 流程

### 负责文件

`src/ai.c`                 663行    | AI 寻路与决策 
`include/ai.h`             30行     | AI 接口声明 
`src/ui.c`                 779行    | 菜单流程 + 游戏循环 
`include/ui.h`             30行     | UI 接口声明 
`src/input.c`              157行    | 键盘 + 鼠标输入 
`src/input_gamepad.c`      80行     | XInput 手柄输入 
`include/input.h`          40行     | 输入接口声明 
`include/input_gamepad.h`  15行     | 手柄接口声明 
`src/audio.c`              113行    | 背景音乐 + 音效 
`include/audio.h`          20行     | 音频接口声明 
`src/main.c`               123行    | 程序入口 + 崩溃捕获 

### 技术栈
C 语言 + Win32 API + XInput + WinMM

### 具体职责
- **AI 系统**：BFS 寻路 + 三档难度评分策略
  - 低难度：贪心寻最近食物
  - 中难度：综合评分（距离 + 道具价值 + 风险）
  - 高难度：射击线计算 + 路径截断 + 事件感知（轰炸区/箭雨规避）
- **输入系统**：
  - 键盘：WASD + 方向键 + E/1/2/P/R（Win32 `GetAsyncKeyState`）
  - 鼠标：光标方位判定方向 + 左键射箭（EasyX `GetMouseMsg`）
  - 手柄：XInput 双控制器 + 左摇杆方向 + RB 射箭
  - 操控方式选择：5 种操控方式分配给 P1/P2
- **音频系统**：
  - 背景音乐循环（WinMM `mciSendString`）
  - 11 种事件音效异步播放（`PlaySound`）
- **UI 流程**：
  - 欢迎菜单 → 地图大小 → 操控方式 → 玩法规则 → 难度选择
  - 游戏循环：多源输入分发 + 帧率控制 + 暂停/恢复
  - 设置界面：5 项设置的读取/修改/持久化
  - 所有菜单适配鼠标 hover + 手柄 D-pad 导航
- **程序入口**：模块初始化 + 崩溃捕获（`SetUnhandledExceptionFilter`）

### 接口约定

`game.h` 中声明的函数为对外接口，卢麒云和刘景炫通过这些接口访问游戏状态：

```c
// 卢麒云调用（渲染层）
Game_isInside(state, pos)     // 判断坐标有效性
Game_isFood(cell)             // 判断是否食物
Game_getSnake(state, index)   // 获取蛇数据
Game_isInBombZone(state, pos) // 判断是否在轰炸区
// ... 等 30+ 个公开函数

// 刘景炫调用（UI/输入层）
Game_init(state, config)      // 初始化游戏
Game_update(state, deltaMs)   // 更新一帧
Game_setPlayerDirection()     // 设置玩家方向
Game_playerFireArrow()        // 玩家射箭
// ... 等
```
