## 二、黄海彬（40%）— 游戏核心逻辑 + 数据结构

### 负责文件

| 文件 | 行数 | 职责 |
|------|------|------|
| `src/game.c` | 1,823 | 游戏全部规则逻辑 |
| `include/game.h` | 45 | 游戏逻辑接口声明 |
| `include/common.h` | 277 | 公共枚举、结构体、常量 |
| `src/common.c` | 114 | 工具函数实现 |

### 技术栈
**纯 C 语言**（C99 标准，无 C++ 特性）

### 具体职责
- 地图生成：墙壁、障碍物、食物、道具的随机放置
- 蛇移动：`StepPlan` 决策-执行分离模式，N 步增长机制
- 碰撞检测：单蛇自身碰撞、双蛇互碰（头碰头/碰身体）
- 道具系统：11 种道具类型的生成、拾取、效果
- 弓箭飞行物：发射、飞行、命中判定、无主箭矢
- 随机事件：地图轰炸（3 区爆破）+ 刀光箭影（边界射箭）
- 计分系统：速度档影响食物分值
- 时间判定：限时模式倒计时、多人模式时间到比分数
- 随机数生成：LCG 高位取模

## 三、卢麒云（30%）— 图形渲染 + UI 界面 + 粒子特效

### 负责文件

| 文件 | 行数 | 职责 |
|------|------|------|
| `src/render_easyx.c` | 2,119 | 全部图形渲染和 UI |
| `include/render.h` | 70 | 渲染接口声明 |

### 技术栈
**C 语言 + EasyX 图形库**（纯 GDI 渲染，无 GPU 加速）

### 具体职责
- EasyX 窗口管理：分辨率切换、全屏适配（Win32 修改窗口样式）
- 贴图系统：3 套皮肤（像素森林/霓虹夜行/冰原挑战）共 48 张贴图加载
- 菜单 UI：渐变背景 + 编号卡片按钮 + 装饰小蛇动画 + 飘浮粒子
- 游戏内 HUD：棋盘左上/右上/底部信息条 + 卡片化侧栏（分数/道具/事件/速度档）
- 棋盘渲染：大地图局部视口（以蛇头为中心）、地面纹理平铺
- 粒子系统：200 粒子池 + 吃食物/死亡/轰炸触发
- 动画效果：分数弹跳、预警脉冲、死亡红闪、文字发光/描边
- 霓虹灯效：霓虹夜景皮肤的棋盘灯光动画
- 轰炸区视觉：红色警告 → 橙色预警 → 深红爆破三态
- 分辨率适配：`menuScale` + `hudScale` 自动缩放

## 四、刘景炫（30%）— AI 决策 + 输入系统 + 音频 + UI 流程

### 负责文件

| 文件 | 行数 | 职责 |
|------|------|------|
| `src/ai.c` | 663 | AI 寻路与决策 |
| `include/ai.h` | 30 | AI 接口声明 |
| `src/ui.c` | 779 | 菜单流程 + 游戏循环 |
| `include/ui.h` | 30 | UI 接口声明 |
| `src/input.c` | 157 | 键盘 + 鼠标输入 |
| `src/input_gamepad.c` | 80 | XInput 手柄输入 |
| `include/input.h` | 40 | 输入接口声明 |
| `include/input_gamepad.h` | 15 | 手柄接口声明 |
| `src/audio.c` | 113 | 背景音乐 + 音效 |
| `include/audio.h` | 20 | 音频接口声明 |
| `src/main.c` | 123 | 程序入口 + 崩溃捕获 |

### 技术栈
**C 语言 + Win32 API + XInput + WinMM**

### 具体职责
- **AI 系统**：BFS 寻路 + 三档难度评分策略
  - 低难度：贪心寻最近食物
  - 中难度：综合评分（距离 + 道具价值 + 风险）
  - 高难度：射击线计算 + 路径截断 + 事件感知（轰炸区/箭雨规避）
- **输入系统**：
  - 键盘：WASD + 方向键 + E/1/2/P/R（Win32 `GetAsyncKeyState`）
  - 鼠标：光标方位判定方向 + 左键射箭（EasyX `GetMouseMsg`）
  - 手柄：XInput 双控制器 + 左摇杆方向 + RB 射箭
  - 操控方式选择：5 种操控方式分配给 P1/P2
- **音频系统**：
  - 背景音乐循环（WinMM `mciSendString`）
  - 11 种事件音效异步播放（`PlaySound`）
- **UI 流程**：
  - 欢迎菜单 → 地图大小 → 操控方式 → 玩法规则 → 难度选择
  - 游戏循环：多源输入分发 + 帧率控制 + 暂停/恢复
  - 设置界面：5 项设置的读取/修改/持久化
  - 所有菜单适配鼠标 hover + 手柄 D-pad 导航
- **程序入口**：模块初始化 + 崩溃捕获（`SetUnhandledExceptionFilter`）

### 接口约定（关键）

黄海彬在 `game.h` 中声明的函数即为对外接口，卢麒云和刘景炫只通过这些接口访问游戏状态：

```c
// 卢麒云调用（渲染层）
Game_isInside(state, pos)     // 判断坐标有效性
Game_isFood(cell)             // 判断是否食物
Game_getSnake(state, index)   // 获取蛇数据
Game_isInBombZone(state, pos) // 判断是否在轰炸区
// ... 等 30+ 个公开函数

// 刘景炫调用（UI/输入层）
Game_init(state, config)      // 初始化游戏
Game_update(state, deltaMs)   // 更新一帧
Game_setPlayerDirection()     // 设置玩家方向
Game_playerFireArrow()        // 玩家射箭
// ... 等
```

## 七、Git 多版本管理

### 7.1 仓库信息

- 平台：GitHub
- 地址：`https://github.com/DarthSea/BUPT_Eating_Snake_Graphics`
- 默认分支：`master`
- 访问方式：HTTPS（需要 VPN 代理）

### 7.2 分支策略

```
master          ← 主分支，始终可编译运行
  ├── feature/game-core    ← 黄海彬：游戏核心逻辑
  ├── feature/render       ← 卢麒云：渲染和 UI
  ├── feature/ai-input     ← 刘景炫：AI + 输入 + 音频 + UI 流程
  └── develop              ← 集成分支（三人代码合并测试）
```

### 7.3 工作流程

**每人每天的标准操作：**

```bash
# 1. 拉取最新 master
git checkout master
git pull origin master

# 2. 切换到自己的功能分支
git checkout feature/你的分支

# 3. 合并 master 的最新改动（避免冲突积累）
git merge master

# 4. 写代码...

# 5. 提交
git add src/你的文件.c
git commit -m "feat: 简短描述做了什么"

# 6. 每天结束时推送
git push origin feature/你的分支
```

**集成阶段（Phase 3-4）：**

```bash
# 三人的代码合并到 develop 分支测试
git checkout develop
git merge feature/game-core
git merge feature/render
git merge feature/ai-input

# 编译验证
MSBuild BUPT_Eating_Snake_Graphics.vcxproj /p:Configuration=Debug /p:Platform=x64 /m

# 测试通过后合并到 master
git checkout master
git merge develop
git push origin master
```

### 7.4 提交规范

| 前缀 | 用途 | 示例 |
|------|------|------|
| `feat:` | 新功能 | `feat: 添加碰撞检测函数` |
| `fix:` | 修 Bug | `fix: 修复 50x50 道具不生成` |
| `docs:` | 文档 | `docs: 更新设计说明书` |
| `refactor:` | 重构 | `refactor: 提取道具生成函数` |

### 7.5 冲突解决

1. 每天至少 `git pull` 一次，避免长时间不同步
2. 出现冲突时，**当面沟通解决**，不要强制覆盖
3. `common.h` 的修改需要通知另外两人
4. 编译命令统一：MSBuild Debug x64，目标 0 错误 0 警告
