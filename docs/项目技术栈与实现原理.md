## 四、核心技术实现

### 4.1 蛇移动 — StepPlan 模式

每步移动前构建 `StepPlan` 结构体，将"决策"和"执行"分离：

```c
typedef struct StepPlan {
    Pos next;        // 下一步位置
    CellType item;   // 目标格物品
    bool dead;       // 是否死亡
    bool grow;       // 是否增长
    bool shieldUsed; // 护盾触发
} StepPlan;
```

流程：`buildStepPlan` → 碰撞检测 → `applySnakeMove` → `applyItemEffect`

### 4.2 碰撞检测

- **单人**：头撞墙/障碍/自身 → 死
- **双蛇**：头碰头同归于尽，头碰对方身体 → 死
- **轰炸事件**：蛇在爆破区且 bombActive → 护盾消耗或死亡
- 反方向输入被忽略，不会死亡

### 4.3 AI 系统（BFS + 评分）

- **低难度**：BFS 寻最近食物 + 安全空地
- **中难度**：候选方向综合评分（距离 + 道具 + 风险 + 攻击）
- **高难度**：中难度 + 射击线计算 + 路径截断预判
- AI 感知轰炸区（BFS visited 矩阵标记炸弹区为不可达）
- AI 箭雨期间远离边界

### 4.4 随机事件系统

| 事件 | 机制 | 视觉 |
|------|------|------|
| 地图轰炸 | 3 个矩形区覆盖 1/4 地图，每 3s 爆破 | 橙红预警 → 深红爆破 |
| 刀光箭影 | 边界墙格向场内射无主箭矢 | 黄色闪烁 → 箭矢飞行 |

- 多样模式专属，每 10s 触发
- 限时挑战间隔缩短 25%，渡过 +100 分

### 4.5 大地图视口

- 20×20：完整显示
- 50×50 / 100×100：局部视口以蛇头为中心
- `cellSizeForMap` → `visibleCellsForMap` → `clampViewportStart`
- 渲染仅遍历可见范围

### 4.6 全屏实现

EasyX 无原生全屏 API，通过 Win32 修改窗口样式：
```c
// 全屏：WS_POPUP 弹窗
SetWindowLongPtr(hwnd, GWL_STYLE, WS_POPUP | WS_VISIBLE);
// 窗口：可调整的叠加窗口
SetWindowLongPtr(hwnd, GWL_STYLE, WS_OVERLAPPED | WS_CAPTION | ...);
```

### 4.7 粒子系统

```c
typedef struct Particle {
    bool active;
    float x, y, vx, vy;  // 位置 + 速度
    int lifeMs;           // 生命周期
    COLORREF color;
    int radius;
} Particle;
```

- 池大小 200，每帧遍历更新位置 + 缩小
- 吃食物 / 死亡 / 轰炸爆破触发
- 性能监控：avgMs > 40 自动禁用

### 4.8 多输入系统

| 输入 | 方向 | 射箭 | 开始游戏 |
|------|------|------|----------|
| 键盘 WASD | W/A/S/D | E | 按方向键 |
| 键盘 方向键 | ↑↓←→ | / | 按方向键 |
| 鼠标 | 光标相对蛇头方位 | 左键 | 左键点击 |
| 手柄 | 左摇杆 | RB | RB 或摇杆 |

- 单人/本地多人开战前自选操控方式（5 选 1 或 5 选 2）
- 所有菜单（欢迎/变体/难度/皮肤/设置/结算）支持鼠标 hover + 点击、手柄 D-pad 导航 + A 确认 + B 返回

### 4.9 随机数生成

LCG 线性同余：`seed = seed * 1103515245 + 12345`  
取模时用 `(seed >> 16) % limit` 避免低位周期性偏差

### 4.10 渲染优化

- 双缓冲：`BeginBatchDraw()` / `FlushBatchDraw()`
- 轰炸区：每区一个整矩形（3 次 GDI 调用），而非逐格绘制
- 大地图视口裁剪

### 4.11 卡片化侧栏

游戏内右侧信息栏使用卡片方块化布局替代纯文字排列：

- 每张卡片为 8px 圆角矩形，间距 6px
- 模式卡片：蓝色 3px 左边条 + 模式名（16px）+ 副信息（12px 灰色）
- 事件卡片（有事件时）：红色 1px 外框 + 事件名 + 8px 进度条
- 分数卡片：居中"玩家得分"标签（11px）+ 发光大字（28px）+ 道具标签行
- 道具标签：暗底小方框（54×22）+ 纯文字 `"长度 8" "弓箭 1" "护盾 0"`
- 多人模式：P1 蓝色顶边卡片 + P2 绿色顶边卡片，各含得分和道具标签
- 底部卡片锚定底边，显示皮肤名和操作提示

### 4.12 文字特效

基于 EasyX LOGFONT 多次绘制实现，无需外部字体库：

| 效果 | 实现 |
|------|------|
| 发光 | 先画 4 个偏移暗色文字，再画主文字 |
| 描边 | 先画 8 方向偏移描边色文字，再画主文字 |
| 居中发光 | 先测量文字宽度计算居中坐标，再画发光层 + 主文字 |

### 4.13 菜单响应式布局

按钮和设置行宽度基于窗口百分比计算：
- 主按钮 `gWindowWidth * 55%`（280~500px）
- 小按钮 `gWindowWidth * 27%`（180~280px）
- 设置行左边距 `gWindowWidth * 12%`（120~260px）
