# UI 沉浸HUD+高质感卡片 设计规格书

> 2026-06-16

## 一、目标

将游戏 UI 升级为"沉浸 HUD + 高质感卡片"混合风格：
- 棋盘上叠加半透明 HUD 信息条（不遮挡游戏区域）
- 侧栏保持卡片化但提升精致度（更深阴影、分隔线、发光数字、边框标签）

---

## 二、棋盘 HUD 覆盖层

### 2.1 左上角 — 模式 + 速度档

```
┌──────────────┐
│ 单人  ⚡+1   │  ← 半透明黑底(RGBA 0,0,0,0.7) + 蓝色下划线2px
└──────────────┘
```

位置：`BOARD_LEFT + 6, BOARD_TOP + 6`
内容：`模式名(12px 蓝)` + `速度档(11px 绿)`
仅在非多人模式显示速度档。

### 2.2 右上角 — 剩余时间

```
┌──────────┐
│ ⏱ 42s   │  ← 半透明黑底 + 蓝色下划线
└──────────┘
```

位置：`BOARD_LEFT + boardSize - 右偏移, BOARD_TOP + 6`
内容：`⏱ Ns (14px 白)`
仅在限时挑战、本地多人模式显示。
最后10秒变红 `COLOR_DANGER`。

### 2.3 底部中 — 道具状态栏

```
    🍖 8    🏹 1    🛡 0
```

位置：`BOARD_LEFT + boardSize/2 居中, BOARD_TOP + boardSize - 28`
使用半透明黑底标签（三个并排）。图标用像素绘制。

## 三、侧栏卡片增强

### 3.1 全局
- 卡片背景：`COLOR_CARD` (38,45,58)
- 面板背景：`COLOR_PANEL` (22,27,38) — 已改
- 卡片阴影：`COLOR_SHADOW` (12,15,22) + 3px 偏移
- 卡片间距：8px
- 文字缩放：`txtScale = 面板宽/240` (0.75~1.5)

### 3.2 模式卡片
- 蓝色 4px 左边条 `COLOR_ACCENT`
- 主标题 16×txtScale px
- 副信息 12×txtScale px 灰色

### 3.3 分数卡片
- 居中 "玩家得分" 标签 11×txtScale px 大写灰色
- 金色分数 28×txtScale px + `drawCenteredTextGlow` 发光
- 分隔线 `COLOR_BORDER` 1px（宽度 60% 居中）
- 下方道具标签行：暗底 + 1px 边框 + 图标

### 3.4 道具标签
- 背景 `COLOR_BG` + 边框 `COLOR_BORDER` 1px
- 尺寸 62×24 × txtScale，圆角 5px
- 左侧像素图标（蛇身/弓箭/盾）+ 右侧文字
- 间距动态计算

### 3.5 速度档卡片
- 左侧 "速度档" 13×txtScale
- 右侧粗体 "+1" 14×txtScale 绿色 + ⚡小方块

### 3.6 事件卡片
- 红色 `COLOR_DANGER` 1px 全边框
- 事件名 + 倒计时
- 进度条 8px 高
- 预警文字脉冲

### 3.7 多人 P1/P2 卡片
- P1：蓝色 `COLOR_ACCENT` 3px 顶边
- P2：绿色 `COLOR_POSITIVE` 3px 顶边
- 各含：标题 + 分数 + 道具标签
